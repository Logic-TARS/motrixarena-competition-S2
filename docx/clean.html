2. 安装Conda

mkdir -p ~/miniconda3wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda3/miniconda.shbash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3rm -rf ~/miniconda3/miniconda.sh~/miniconda3/bin/conda init bashsource ~/.bashrc


3. 创建仿真环境“motrixsim0508”

cd /opt/sim_soccer2/simulation/motrixsimconda create -n motrixsim0508 python=3.12 -yconda activate motrixsim0508pip install -r requirements.txt


4. 创建决策环境“k1”

cd /opt/sim_soccer2conda create -n k1 python=3.8 -yconda activate k1pip install -r decider/requirements.txt


5. 启动 Sim Manager 服务

在 sim_soccer2 根目录下启动 Sim Manager 服务。

打开命令行终端，运行以下命令（运行后请勿关闭该命令行窗口）：

cd /opt/sim_soccer2conda activate motrixsim0508python simulation/motrixsim/sim_manager.py --host 0.0.0.0 --port 8000


6. 访问 Sim Manager

打开浏览器（可使用桌面自带的火狐浏览器），
访问地址 http://127.0.0.1:8000/ 。

05 启动决策端(Decider)

打开新终端后，进入 sim_soccer2 项目根目录即可配置并启动决策端。

方式 A：单机器人启动（推荐用于调试）

打开新的终端，激活 k1 环境，并使用 Sim Manager 分配的 ZMQ 端口分别启动红蓝队伍的机器人：

cd /opt/sim_soccer2conda activate k1
# 启动红队 0 号（请将 --port 替换为 Sim Manager 分配的 ZMQ 端口）python3 decider/decider.py --simulation --ip 127.0.0.1 --port 5555 --color red --id 0
# 启动蓝队 0 号python3 decider/decider.py --simulation --ip 127.0.0.1 --port 5555 --color blue --id 0

方式 B：一键启动整支球队（适用于 Linux / macOS）

使用该脚本，系统会通过 screen 工具为每个机器人单独创建一个会话，方便批量管理：

# 按 match_config 默认配置自动启动整队./decider/scripts/start_team.sh
# 自定义启动数量（例如：红队 2 台，蓝队 1 台）./decider/scripts/start_team.sh --red 2 --blue 1
# 重启全部机器人./decider/scripts/start_team.sh --restart
# 停止全部机器人./decider/scripts/start_team.sh --kill

进入/查看特定机器人的日志：

输入 screen -r decider_red_0 进入会话。


退出日志会话（不中断进程）：

在键盘上依次按下 Ctrl+A 然后按 D 退出。
